Primeiros passos com CSS

Introdução ao CSS

CSS é uma linguagem de estilo utilizada para definir a apresentação de documentos HTML. Com CSS, você pode controlar a aparência de elementos, como cores, fontes, espaçamento e layout.

Para começar a usar CSS, você pode criar um arquivo separado com a extensão .css e vinculá-lo ao seu documento HTML usando a tag <link> no cabeçalho do HTML.

Além disso, você pode aplicar estilos diretamente em elementos HTML usando o atributo style, mas é recomendado separar o CSS em arquivos externos para manter o código mais organizado.
