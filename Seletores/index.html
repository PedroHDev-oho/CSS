Seletores CSS

Bem-vindo!

No CSS temos os seletores por ID:

  • Seletor por Tipo:Busca uma tag HTML especifica
  • Seletor por ID:Busca um elemento atributo "ID"
  • Seletor por Classe:Busca uma tag HTML especifica
  • Seletor Universal:Seleciona todos os elementos HTML
  • Seletor de Atributo:Seleciona elementos que possuem um atributo especifico em nosso documento
